# How to Share This on GitHub

## Option 1: Standalone Portfolio Repository (Recommended)

1. Create a new public repository on GitHub named **`program-management-leader`**
2. Push this folder:

```bash
cd ~/Projects/program-management-leader
git init
git add .
git commit -m "Add program management leader portfolio"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/program-management-leader.git
git push -u origin main
```

3. On GitHub, go to **Settings ? General ? Social preview** and upload a screenshot of the README for link previews.

## Option 2: GitHub Profile README

To show this on your GitHub profile page (`github.com/YOUR_USERNAME`):

1. Create a repository with the **exact same name** as your GitHub username (e.g., `github.com/shradha-tripathi/shradha-tripathi`)
2. Copy the contents of `README.md` into that repository's README
3. It will automatically appear on your profile

## Option 3: GitHub Pages (Optional Visual Site)

For a web page version, enable **GitHub Pages** in repository settings and use the README as the landing content, or add an `index.html` later.

## Tips for Maximum Impact

- Pin this repository to your GitHub profile (up to 6 pinned repos)
- Add your LinkedIn URL to the badge links in `README.md`
- Keep impact metrics updated as you ship new programs
- The Mermaid diagrams render automatically on GitHub — no extra setup needed
